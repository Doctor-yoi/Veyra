# Veyra for Visual Studio Code

English | 简体中文见下文

Syntax highlighting and snippets for `.vey` files, the source language of [Veyra](https://github.com/Doctor-yoi/Veyra).

Install from source:

```bash
cd editors/vscode
npx @vscode/vsce package
code --install-extension veyra-0.1.0.vsix
```

Format files with `veyra fmt`.

---

为`.vey`文件提供语法高亮与代码片段，`.vey`是[Veyra](https://github.com/Doctor-yoi/Veyra)的源码语言。

从源码安装的命令见上文，格式化请使用`veyra fmt`。
